# Disclaimer

This project was performed for educational purposes against a locally hosted, intentionally vulnerable DVWA instance.

- No third-party or production systems were in scope.
- Do not test systems without explicit authorization.
- Screenshots must be reviewed and sanitized before public sharing.
- Remove session cookies, authentication tokens, passwords, personal data, and private network details before committing evidence.
- Findings are limited to what the available evidence demonstrates. Attempted tests are not automatically confirmed vulnerabilities.
